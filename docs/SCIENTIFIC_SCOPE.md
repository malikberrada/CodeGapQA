# Scientific scope and claim boundaries

The public result certifies a frozen two-feature local parity witness on one
60-qubit, code-derived circuit family under three local unitary-fold stress
levels.

It establishes, for the registered panel and attack suite:

- positive simultaneous finite-shot lower-bound margins at folds 1, 3, and 5;
- a calibration-robust local-witness certificate;
- a conditional verification/simulation operation-count gap above the
  registered target;
- a pilot-informed but confirmatory-data-separated analysis design.

It does not establish:

- a complete experimental implementation of exact Hidden Code Sampling;
- a full-distribution total-variation certificate;
- an unconditional classical lower bound;
- a measured wall-clock quantum speedup;
- universal code-family optimality or backend-independent robustness.
