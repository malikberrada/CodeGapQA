# Public data and code availability

The public package contains:

- the manuscript PDF and LaTeX sources;
- sanitized confirmatory QASM for folds 1, 3, and 5;
- aggregate fold-resolved certificate metrics;
- a machine-readable public certificate summary;
- SHA-256 checksums;
- Open Quantum attribution and compliance metadata.

The public package excludes:

- authentication credentials and secrets;
- account and organization metadata;
- email addresses;
- provider job identifiers;
- private provider records and dashboard exports;
- the private immutable audit archive.

The private audit archive is preserved separately. Public summaries are derived records and do not replace or rewrite the frozen originals.
